## Overview

In this hands-on lab, you will act as a Power User or IT Administrator at Contoso Electronics, overseeing a shared OneDrive folder of Project Orion business documents spanning Sales, Procurement, Security, and Executive functions. File naming is inconsistent, governance is weak, and a compliance review is approaching. You will use Microsoft 365 Copilot Cowork - an agentic AI layer that orchestrates OneDrive, SharePoint, Excel, and Teams - to classify Project Orion files by business function and rename them using an AI-generated naming convention, run a full governance audit covering duplicates, staleness, sharing risks, and ownership gaps, and generate an Excel governance tracker with a summary posted to Teams. Every bulk file operation requires your explicit approval before it executes.

## Objectives

In this lab, you will perform the following:

- **Task 1:** Automated File Classification and Renaming

- **Task 2:** OneDrive and SharePoint Governance Audit

- **Task 3:** AI-Generated Excel Tracking and Teams Reporting

## Task 2: OneDrive and SharePoint Governance Audit


## Task 3: AI-Generated Excel Tracking and Teams Reporting

In this task, you will ask Cowork to generate an Excel governance tracker with one row per file, then post a short cleanup summary with a link to the workbook in a Teams channel - all from a single instruction.

1.  In the existing **Copilot Cowork** session, enter the following **prompt (1)** and click **Send (2)** to submit the request.

    ```
    Using the inventory and audit results already in this session - do not re-scan any files - create 'Project Orion File Governance Tracker.xlsx' in my "Lab Files" folder with one row per file and these columns: name, type, business function, last modified, sharing status, action taken.

    Then post a 3-line summary of today's cleanup to my Teams channel 'Retail' with a link to the workbook.

    Reply with a one-line confirmation only.
    ```

    ![](./media/image21.png)

2.  Click on **Approve** and approve all the requests generated by cowork.

    ![](./media/image22.png)

3.  If the **Post to channel?** card appears with an empty message body enter the below **message (1)** in the box and click on **Send (2)**.

    ```
    Project Orion file cleanup complete. All 11 files classified by business function (Sales, Procurement, Security, Executive) and renamed using a YYYY-MM-DD_BusinessFunction_DocType convention.

    Governance audit flagged 1 exact duplicate, 2 superseded documents, and 1 file with no assigned owner. The two superseded documents have been archived; remaining findings are pending review.

    Full details in the governance tracker linked above.
    ```
